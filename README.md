# IPhySims Curated Simulations

A curated collection of peer-reviewed, certified physics simulations.

## About

This repository contains simulations that have been reviewed and certified by IPhySims. Each simulation has been evaluated for:
- Scientific accuracy
- - Code quality
  - - Reproducibility
    - - Educational value
     
      - ## Browse Simulations
     
      - Simulations are organized by physics domain:
      - - Classical Mechanics
        - - Electromagnetism
          - - Quantum Mechanics
            - - Thermodynamics and Statistical Mechanics
              - - Optics and Photonics
                - - Nuclear and Particle Physics
                  - - Astrophysics and Cosmology
                    - - Condensed Matter Physics
                      - - Fluid Dynamics
                        - - Computational Physics Methods
                         
                          - ## Certification Badge
                         
                          - Simulations in this repository display the IPhySims Verified badge, indicating they have passed our rigorous peer review process.
                         
                          - ## Contribute
                         
                          - To submit a simulation for certification, see the [submissions repository](https://github.com/IPhySims/submissions).
